## 詳細説明文（ストアの商品説明欄）

```
ebayカテゴリー発見君 — eBay 手動出品のための「カテゴリID 検索」専用ツールです。

■ できること
・キーワード検索 — 英語（Wristwatch, Reel, Card など）でも日本語ジャンル語（トレカ、フィギュア、腕時計、マフラー、ブレーキ など）でも検索できます。スペース区切りの複合語（例:「トレカ シングル」「バイク パーツ」）にも対応。
・ツリーで辿る — 35 の大分類（eBay Motors を含む）から枝を辿って、目的のカテゴリまでドリルダウンできます。
・IDコピー — 見つけた categoryID をワンクリックでコピーできます。
・検証 — 手元の categoryID を入力すると、その正式なカテゴリパスを表示します。存在しないIDは「存在しません」と表示されます。
・絞り込み — 部門（eBay Motors を含む）や「厳選版のみ」（よく使う主要カテゴリだけに絞る）で候補を絞り込めます。

■ 収録データ（EBAY_US, treeVersion 134）
・18,076 葉カテゴリ / 35 部門
・厳選版 6,822 件（一括出品ツール等でよく使う主要カテゴリ）
・日本語訳 6,822/6,822（厳選版カバレッジ100%）
・うち eBay Motors（自動車・オートバイ・ボート・ATV/UTV等の部品専用ツリー、公式 Taxonomy API Tree ID 100）: 2,965 葉、部品用途に厳選した 1,891 件に日本語訳つき

■ v1.3.0の変更点（新機能）
・eBay Motors ツリー（公式 Taxonomy API、Tree ID 100）を追加。自動車・バイク・ボート・ATV/UTV・トラック・芝刈機等の部品カテゴリ 2,965 件が新たに検索・閲覧できるようになりました。
・部品出品でよく使う 1,891 件を厳選し、すべてに日本語訳を追加（マフラー、ブレーキ、ヘッドライト、ミラー、ステアリング、エンジン、キャブレター、バッテリー 等）。
・部門の絞り込みに「eBay Motors」を追加。
・Motors向けの日本語ジャンル語を追加（車/自動車、バイク/オートバイ、パーツ/部品、マフラー、ホイール、タイヤ、ブレーキ、ヘッドライト、ミラー、ステアリング、シート、エンジン、キャブレター、バッテリー、ボート、トラック、工具 など）。
・選択したカテゴリが eBay Motors のものであるときは「Motors」タグを表示します。

■ 安全性（eBay アカウント保護）
・完全オフラインで動作します。実行時に eBay や外部サーバーへ一切アクセスしません（host_permissions なし）。
・スクレイピング・自動操作は一切行いません。データは公式 Taxonomy API から取得済みのCSV/JSONから生成した静的データのみを同梱しています。
・「eBay のカテゴリページを開く」リンクは、あなたが手動でクリックしたときだけ、あなたのブラウザで eBay の該当ページを開く任意機能です。拡張自身がアクセスするわけではありません。
・権限は sidePanel（画面表示）、clipboardWrite（IDコピー）、storage（設定の保存）の3つのみで、v1.2.0から変更ありません。

対応 Chrome バージョン: 114 以上（サイドパネル機能のため）。
```

## 「プライバシーの取り扱い」フォーム回答（Chrome Web Store Developer Dashboard）

v1.2.0 申請時から**変更なし**（権限追加なし、外部通信なし、個人データ収集なし）。フォームの各設問への回答方針:

- **単一の目的**: eBay に手動出品する際に使う categoryID を、同梱の静的データからオフラインで検索・閲覧・コピー・検証するためだけの拡張です。
- **permissions の正当化**:
  - `sidePanel`: 検索・ツリー・検証の画面をサイドパネルに表示するために必要。
  - `clipboardWrite`: 見つけた categoryID をワンクリックでクリップボードにコピーするために必要。
  - `storage`: お気に入り・直近の絞り込み条件など、利用者ローカルの設定を保存するために必要（外部送信なし）。
- **リモートコード**: 使用していません。すべてのロジックは同梱ファイル内に完結しています。
- **データ収集**: 個人を特定できる情報・利用状況の外部送信は一切行っていません（プライバシーポリシー参照）。
- **プライバシーポリシーURL**: https://naokijodan.github.io/ebay-category-finder-privacy/ （v1.3.0での変更なし。権限・データ取り扱いに変更がないため、ポリシー本文の改訂は不要と判断）。

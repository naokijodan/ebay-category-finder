プライバシーポリシー

対象: Chrome 拡張機能「ebayカテゴリー発見君」
最終更新日: 2026年5月24日

本拡張機能は、利用者の個人情報を含む一切のデータを収集・保存・送信しません。 すべての処理は利用者のブラウザ内（オフライン）で完結し、eBay を含む外部サーバーには一切アクセスしません。

1. 収集する情報

本拡張機能は、以下を含むいかなる情報も収集しません。

  • 氏名・メールアドレス等の個人情報
  • 閲覧履歴・Cookie・位置情報
  • 検索欄に入力した語句や操作内容
  • その他、利用者を識別しうる一切のデータ

2. データの送信・外部通信

本拡張機能は外部のサーバーと通信しません。検索や閲覧は、拡張機能に同梱された静的なデータファイルのみを用いて、 利用者のブラウザ内で完結します。eBay のウェブサイトや API にもアクセスしません。

3. 権限の利用目的

  • サイドパネル (sidePanel): 検索画面をブラウザのサイドパネルに表示するためにのみ使用します。
  • クリップボードへの書き込み (clipboardWrite): 利用者が選んだカテゴリ ID を、ボタン操作でクリップボードにコピーするためにのみ使用します。

4. 第三者への提供

収集するデータが存在しないため、第三者への提供・販売・共有は一切ありません。

5. 同梱データについて

本拡張機能には、eBay の公開カテゴリ情報（カテゴリ名・カテゴリ ID・階層）をオフラインで参照するための静的データを同梱しています。 これは公開情報であり、利用者個人のデータではありません。

6. 子どものプライバシー

本拡張機能は個人情報を収集しないため、年齢を問わず安全にご利用いただけます。

7. ポリシーの変更

内容を変更する場合は、本ページの「最終更新日」を更新して掲示します。
